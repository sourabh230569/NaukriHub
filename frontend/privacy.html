Privacy Policy

Last updated: September 2026

Academic project notice: JobPortal is a web development academic project. This policy describes how demo data is handled within the project. No personal data is collected for commercial purposes or shared with any third party.

1. Information We Collect

When you use JobPortal, we collect only the information required to provide the demonstration features of this application:

  • Name: The full name you provide during registration, used to personalise your dashboard.
  • Email address: Used as a unique identifier for your account and to facilitate login.
  • Password: Stored as a secure bcrypt hash. Your plain-text password is never stored.
  • Application activity: Records of which job listings you have applied to and their status.

2. How We Use Your Information

Information collected in this application is used solely for the following demonstration purposes:

  • Authenticating your login session.
  • Displaying your name and email in your account dashboard.
  • Associating your job applications with your account.
  • Allowing administrators to view applicant information for the purpose of the demonstration workflow.

3. Data Storage

All data is stored in a local SQLite database file on the server running this application. No data is transmitted to external services, cloud databases, or third-party APIs.

Because this is an academic project, the database may be reset, modified, or deleted without notice during development or evaluation cycles. You should not use real personal information when creating accounts.

4. Cookies and Local Storage

This application uses the following browser storage mechanisms:

  • HTTP-only cookie: A session token may be set as an HTTP-only cookie to maintain your logged-in state securely.
  • localStorage: Your authentication token and basic user profile (name, email, role) are stored in browser localStorage to allow client-side session management.

No tracking cookies, analytics cookies, or advertising cookies are used.

5. Data Sharing

No data collected through this application is shared with any third party, sold, or used for advertising. This application does not integrate with any external analytics, advertising, or data broker services.

6. Security

Reasonable security measures have been implemented for this academic project, including:

  • Passwords are hashed using bcrypt before storage.
  • SQL queries use parameterised statements to prevent injection attacks.
  • JWT authentication tokens are used for session management.
  • Role-based access control prevents users from accessing admin-only data.

However, this application has not undergone a professional security audit. It is not suitable for handling sensitive real-world data and should be used only in a development or demonstration context.

7. Your Rights

Because this is an academic demonstration project, it does not fall under commercial data protection regulations. However, in the spirit of good practice:

  • You may delete your account by contacting the project administrator.
  • You should avoid entering real or sensitive personal information into this application.

8. Changes to This Policy

This policy may be updated during the course of the academic project. The date at the top of this page reflects when it was last revised.
